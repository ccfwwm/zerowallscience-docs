# 认识 ZeroWall Science

ZeroWall Science 是面向科研工作的本地优先 AI 工作台。它把 Agent 对话、科研方法、受控计算、证据记录、文献、文件和成果交付放入同一工作空间。

## 当前正式版本

本批指南已按 **Stable 6.2.0** 核对。该版本于 2026 年 9 月 17 日正式发布，详见 [6.2.0 发布记录](https://github.com/ccfwwm/zerowallscience/releases/tag/v6.2.0)。官网的下载按钮动态读取 Stable 元数据；后续版本以下载页和相应发布记录为准。

当前主要发行形式为 Windows 桌面应用。模型 API、MCP、Zotero、本地 Python、WSL 和 SSH 资源需要按任务配置。

## 能做什么

- 使用项目与会话组织研究目标、输入文件和执行过程。
- 通过 Skills 固定研究步骤，通过 MCP 接入外部工具。
- 结合 Zotero 管理文献、附件和引用。
- 处理本地文件、Office 产物，以及 Python 或 SSH 环境中的计算任务。
- 在 6.2.0 中使用科研图片查重、指定论文分析、多论文对比、证据报告四类科研技能。

系统不会把一段流畅的回答直接当成科研结论。项目、Run、Artifact、Paper、Decision 和审阅记录承担不同职责，让研究过程可以检查、恢复和继续。生成的结论仍需对照原始文献和实际运行结果核验。
