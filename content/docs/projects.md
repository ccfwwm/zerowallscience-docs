# 项目与会话

项目用于组织科研数据、执行环境与产物；会话用于保存围绕任务的对话过程。为每个研究目标使用可识别的项目名称和工作目录，避免把不同实验的输入输出混在一起。

## 建立任务边界

开始前写清目标、输入路径、允许使用的环境和期望输出。长任务分阶段记录结果；将已确认的结论、证据与文件保存到项目中，不只留在聊天消息里。

例如：“读取 input 下的数据，先检查字段和缺失值；把检查报告保存到 output，确认检查结果后再做分析。”

## 删除与继续会话

Stable 6.2.0 删除单个会话时采用局部更新，不重启 Host，也不重载整个主页面。目标会话忙碌时会拒绝删除，其他独立会话可以继续运行。

删除前先结束该会话的任务并确认重要产物已经保存。会话整理不能替代项目备份；对磁盘文件执行删除或覆盖时，仍应独立核对目标路径。
