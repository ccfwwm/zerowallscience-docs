# 可信科研流程

推荐路径是：定义问题与验收标准，形成计划，确认数据与方法，运行计算，收集产物，关联文献和决策，审阅证据覆盖，最后生成交付材料。

## 一次可检查的研究任务

1. 明确问题、输入来源和不纳入的范围。
2. 检查论文身份、文件完整性、数据字段和使用条件。
3. 为计算任务指定环境、工作目录、命令与输出位置。
4. 保留日志、错误信息、产物和实际执行范围。
5. 对照证据撰写结论，区分观察结果、推断与尚未验证的假设。
6. 在交付前检查引用、图片、表格、公式与文件可读性。

## 论文与 PDF

在 6.2.0 中，可以用指定论文分析、多论文对比与证据报告技能组织流程。PDF 默认交由 mineru-document-parser 解析，后续分析使用 Markdown、图片和来源位置。

不要因报告结构完整就认定所有检查已执行。核对缺失依赖、未执行项目、解析失败页和无法确认的来源；补齐后再继续相应任务。

## 失败后恢复

每个 Run 应记录环境、输入、命令、日志和输出。失败时先确认已经完成的步骤、可复用的产物和失败原因，再决定继续还是重跑。结论缺少来源或复现记录时，应明确标为待验证。
