# 文件与 Office

项目文件入口用于浏览研究目录和关联产物。先把原始输入与生成结果分目录保存，避免处理过程中覆盖原文件。

## Office 能力

Stable 6.2.0 集成 Univer Office，并保留已有文件及 HuanLin Office 预览。旧演示文稿服务及其侧栏入口已移除，不再按旧版侧栏教程查找它们。

对于 DOCX、XLSX、PPTX，区分“预览内容”和“修改原文件”：看到预览并不意味着磁盘文件已被改写。要求 Agent 编辑时，应明确原文件路径、输出路径、需要保持的样式或公式。

## 推荐操作

1. 将输入放入项目的 input 目录，生成文件放入 output 目录。
2. 在会话中说明需要读取、生成还是修改，明确保留哪些内容。
3. 让 Agent 返回实际生成的文件路径，并检查文件确实存在。
4. 在桌面 Office 或兼容软件中复核版式、公式、图表、字体与分页。
5. 将确认后的产物关联到对应研究任务；重要交付记录文件校验值。

PDF 分析默认使用 mineru-document-parser，并将解析得到的 Markdown、图片和来源位置交给后续分析。解析器依赖缺失或某一步没有执行时，应保留报告中的缺失说明，不把预览结果视作完整解析。
