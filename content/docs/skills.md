# Skills

Skill 是可复用的方法说明，告诉 Agent 在特定任务中遵守哪些步骤、约束和验收标准。系统可发现内置、项目级、全局和插件提供的 Skills。

## 使用方法

1. 先说明研究目标、输入文件或文献、输出格式。
2. 检查所选 Skill 的适用范围和依赖。
3. 在任务中明确要求使用相应方法，先完成一个小样本。
4. 检查实际执行记录和报告中的缺失项，再扩大范围。

需要反复使用的方法可以保存为项目 Skill；一次性要求直接写在会话中。Skill 不会自动扩大工具权限，涉及副作用的操作仍受 Host 控制。

## 6.2.0 的科研技能

| 技能 | 适合的任务 | 交付时重点检查 |
| --- | --- | --- |
| 科研图片查重 | 检查指定论文或图片中的疑似重复区域 | 原图、候选区域、变换关系和人工复核结论 |
| 指定论文分析 | 分析一篇给定论文的方法与证据 | 论文身份、解析完整性、来源位置和未执行检查 |
| 多论文对比 | 按统一问题比较多篇论文 | 纳入范围、比较口径和逐篇证据 |
| 证据报告 | 汇总已有分析结果 | 结论与来源对应、缺失项和后续验证步骤 |

示例请求：“使用指定论文分析技能分析项目中的 paper.pdf，输出方法、主要结果和限制，并保留对应页码或来源位置。缺失依赖或无法执行的检查单独列出。”

这些技能融合已有图片查重与 ManuSift 内核，支持报告和任务续用。旧科研图片查重侧栏入口已移除，应按技能流程进入。疑似重复不是学术不端定论，仍需核验原始材料与上下文。

版本依据：[6.2.0 发布记录](https://github.com/ccfwwm/zerowallscience/releases/tag/v6.2.0)。
