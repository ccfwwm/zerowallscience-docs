# Windows 安装与更新

1. 从官网首页下载最新 Stable Windows 安装包。
2. 运行安装程序并完成首次启动。
3. 按启动页提示创建本地账号并进入工作台。

升级前应结束正在运行的任务。正式安装包会保留用户目录中的配置和科研数据库；关键项目仍建议先导出或备份。官网的下载按钮读取经过校验的 Stable 元数据，显示版本应与下载文件名一致。

## 核对版本

本批文档按正式发布的 Stable 6.2.0 核对。安装后可在设置最后一项“关于”查看实际应用版本；后续更新以官网 Stable 元数据和对应发布记录为准。

如果浏览器缓存仍显示旧版本，刷新官网后再次检查下载文件名。不要使用来源不明的重新打包安装程序。
