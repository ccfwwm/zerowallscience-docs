# 模型与凭据

模型负责推理，Host 负责权限、路径和执行边界。更换模型不会自动改变文件和执行权限。

## 配置步骤

1. 在设置中选择或添加模型提供方。
2. 填写该提供方要求的 API 地址、凭据与模型名称。
3. 先运行一次简短对话，确认网络、模型名称和接口兼容性。
4. 再让模型执行一个只读任务，检查工具调用与结果展示。

凭据保存在本机凭据系统中；不要把密钥写进对话、项目文件、公开文档或截图。共享项目时，应分别检查目录内容与凭据引用，不把完整用户数据目录直接发送给他人。

## Stable 6.2.0 的默认与免费模型

默认模型保留 deepseek-official/deepseek-v4-flash。6.2.0 移除旧的本地 OpenCode 模块，改由 Zen Free Provider 动态同步并检测当前有效的 -free 模型。

免费模型是否可用以实时目录和检测结果为准，不能把曾经出现过的名称视为长期保证。无需按旧教程启动已移除的本地 OpenCode 模块。

## 排查失败

先区分网络连接、鉴权、额度、模型不存在和工具执行失败。提供方请求失败时，检查其 API 地址与模型名称；工具失败时则检查工具自身的配置和日志。更换模型不一定能修复本地路径或执行环境问题。
